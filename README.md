# Ceiba Docs

Documentation, guides, comparisons, and onboarding content for Ceiba.

Ceiba helps teams add API keys, plans, quotas, usage tracking, and subscription-gated access to an existing Node API without adopting a full gateway.

## What this repo is for

This repository powers the public documentation and onboarding layer for Ceiba, including:

- quickstart guides
- integration tutorials
- architecture overviews
- pricing and plan concepts
- comparisons against DIY and adjacent alternatives
- product education for first-time adopters

## Documentation goals

The docs should help a developer answer these questions quickly:

- What is Ceiba?
- Is it for my use case?
- How do I integrate it into Express or Fastify?
- How do Runtime, SDK, and Control Plane work together?
- How do plans, quotas, and usage enforcement behave?
- How do I go from trial to production?

## Key message

Ceiba is not trying to be a full gateway or broad API management suite.

It is a **Node-first API productization layer** for existing APIs.
